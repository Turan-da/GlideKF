# GlideKF

Official implementation of the paper

**GlideKF: A Gliding Kalman Filter for Stable Single-Target Visual Measurement Under Intermittent Detections**

Jinpeng Zhang, Nanlin Kuang, and Quan Liang

The GlideKF implementation and the cached detection streams used in the OTB100 and UAV123 evaluations will be released here upon publication of the paper. The industrial recordings are confidential and are not included.

For questions, please open an issue.
