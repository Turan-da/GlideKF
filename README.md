# GlideKF

Official implementation of the paper

**GlideKF: A Gliding Kalman Filter for Stable Single-Target Visual Measurement Under Intermittent Detections**

Jinpeng Zhang, Nanlin Kuang, and Quan Liang
School of Computer and Data Science, Fujian University of Technology

GlideKF is a lightweight stabilization layer placed between an object detector and its downstream consumer. It reads only detection boxes and confidence scores and has no learned parameters.

## Status

The paper is under review. The code will be released here upon publication.
